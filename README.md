# Book Reading List Application

A simple app to keep track of books you want to read and books you have finished.

## Live link
https://book-reading-list-psi.vercel.app

## Features
- Add a book with title and author
- Mark a book as finished or back to "to read"
- Remove a book
- Filter by All, To read, Finished
- Your list is saved in the browser, so it stays after refreshing

## How it works
Books are stored in a JavaScript array. Every change saves the array to the browser's localStorage and redraws the list.

## Technologies
HTML, CSS, JavaScript, Vercel

## How to run
Download the files and open `index.html` in a browser.
